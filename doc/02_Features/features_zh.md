# 功能規格

## 核心功能
- Dataset CRUD + 版本控制
- 透過 MinIO Presigned URL 安全上傳
- 全文搜尋 + 標籤
- 下載統計（Dataset 同 Version 級別）

## 協作功能
- 團隊與組織管理
- 角色權限（READ / WRITE / ADMIN）
- 公開分享連結（可設定過期時間）
- 評論 + @提及 + 通知

## 分析功能
- 完整活動日誌
- 30日活動熱力圖
- 版本比較（Diff）

## 匯出功能
- 匯出為 ZIP（包含所有版本）
- 匯出為 CSV
- 匯出為 JSON

## 用戶體驗
- 深色 / 淺色模式
- 響應式設計
- 更好嘅錯誤訊息
- 即時更新
