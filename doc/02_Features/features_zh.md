## 3. 詳細功能說明

### 3.1 用戶認證與權限管理（P0）

**功能描述：**
- 用戶可透過 Email + 密碼註冊與登入
- 使用 JWT 進行身份驗證
- 支援角色：Owner、Collaborator、Viewer
- Dataset 可設定為公開或私人

**主要功能點：**
- 註冊 / 登入 / 登出
- JWT Token 管理
- 基於角色的訪問控制（RBAC）
- Dataset 層級權限

---

### 3.2 Dataset 管理（P0）

**功能描述：**
用戶可以建立和管理訓練數據集，並維持豐富的元數據。

**主要功能點：**
- 建立新 Dataset
- 編輯 Dataset 基本資訊（名稱、描述、任務類型、標籤）
- 設定 Dataset 可見性（公開 / 私人）
- Dataset Card（類似 Hugging Face）
- 刪除 Dataset

---

### 3.3 版本控制系統（P0）

**功能描述：**
為每個 Dataset 提供版本管理能力，確保數據可重現與可追蹤。

**主要功能點：**
- 建立新版本（手動或自動）
- 版本命名（v1.0、日期格式等）
- 查看版本歷史
- 版本之間的差異比較（大小、行數、Metadata）
- 切換與還原版本

---

### 3.4 數據上傳與儲存（P0）

**功能描述：**
支援大型數據檔案的安全、高效上傳與儲存。

**主要功能點：**
- 透過 Presigned URL 直接上傳至 MinIO/S3
- 支援常見格式：JSONL、Parquet、CSV、圖像資料夾
- 檔案大小限制與格式驗證
- 上傳進度顯示
- 儲存路徑與 Metadata 綁定

---

### 3.5 數據預覽與統計（P1）

**功能描述：**
讓用戶快速了解數據集內容與品質。

**主要功能點：**
- 自動計算基本統計（總行數、檔案大小、欄位分佈）
- 預覽前 N 筆數據
- 圖像數據集支援縮圖預覽
- 簡單的數據品質指標

---

### 3.6 協作與分享（P1）

**功能描述：**
支援團隊成員之間的數據協作。

**主要功能點：**
- 將 Dataset 分享給特定用戶
- 設定協作者角色
- 版本層級評論與筆記
- 活動記錄（誰、何時做了什麼）

---

### 3.7 匯出與 API 整合（P1）

**功能描述：**
方便將數據匯出到訓練流程中使用。

**主要功能點：**
- 匯出為 Hugging Face `datasets` 格式
- 提供 REST API 讓訓練腳本存取數據
- 版本指定匯出
- 未來支援直接連接到訓練平台
