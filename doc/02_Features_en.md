# Features

## Core Features
- Dataset CRUD + Versioning
- Secure file upload via MinIO presigned URLs
- Full-text search + Tags
- Download statistics (dataset & version level)

## Collaboration
- Team & Organization management
- Role-based permissions (READ / WRITE / ADMIN)
- Public share links with expiration
- Comments + @mentions with notifications

## Analytics
- Comprehensive Activity Log
- 30-day Activity Heatmap
- Version Comparison (Diff)

## Export
- Export as ZIP (all versions)
- Export as CSV
- Export as JSON

## User Experience
- Dark / Light mode
- Responsive design
- Better error messages
- Real-time updates
