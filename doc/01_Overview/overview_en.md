# Overview

**DatasetForge** is a professional platform for managing AI training datasets. It provides comprehensive tools for version control, team collaboration, permission management, activity tracking, and data export.

## Current Status (May 2026)

DatasetForge is **production-ready** with the following major features completed:

- Full authentication and authorization system
- Dataset versioning and upload (MinIO)
- Team and organization management
- Granular permission system (READ/WRITE/ADMIN)
- Activity logging with heatmap visualization
- Public share links with expiration
- Comments and @mentions
- Version comparison (Diff)
- Download statistics (dataset + version level)
- Multi-format export (ZIP, CSV, JSON)
- Dark mode and responsive UI
- Docker + CI/CD pipeline

The platform is suitable for small to medium teams working with AI datasets.
