# DatasetForge Overview

**Professional AI Training Dataset Management Platform**

DatasetForge is a modern, full-featured platform for managing AI training datasets. It provides powerful version control, team collaboration, permission management, activity tracking, and multi-format export capabilities.

## Key Features

- **Version Control**: Complete version history with metadata
- **Secure Upload**: MinIO Presigned URL for safe file uploads
- **Team Collaboration**: Role-based access control (READ/WRITE/ADMIN)
- **Activity Tracking**: Full audit trail with heatmap visualization
- **Public Sharing**: Time-limited share links with permission control
- **Multi-format Export**: ZIP, CSV, JSON support

## Technology Stack

- **Backend**: Node.js + TypeScript + Express + Prisma + MySQL
- **Frontend**: React 18 + TypeScript + Vite + MUI
- **Storage**: MinIO (S3-compatible)
- **Authentication**: JWT with refresh tokens
