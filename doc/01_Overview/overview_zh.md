# 概覽

**DatasetForge** 係一個專業嘅 AI 訓練資料集管理平台，提供完整嘅版本控制、團隊協作、權限管理、活動追蹤同數據匯出工具。

## 目前狀態（2026年5月）

DatasetForge 已達到 **生產就緒** 狀態，主要功能包括：

- 完整認證與授權系統
- Dataset 版本控制 + 上傳（MinIO）
- 團隊同組織管理
- 細粒度權限系統（READ/WRITE/ADMIN）
- 活動日誌 + 熱力圖視覺化
- 公開分享連結（可設定過期時間）
- 評論 + @提及功能
- 版本比較（Diff）
- 下載統計（Dataset + Version 級別）
- 多格式匯出（ZIP、CSV、JSON）
- 深色模式 + 響應式 UI
- Docker + CI/CD 流程

平台適合中小型團隊使用。
