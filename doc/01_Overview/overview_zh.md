## 1. 項目背景

隨著人工智能（AI）和機器學習（ML）技術的快速發展，訓練數據的品質與管理已成為影響模型性能的關鍵因素。目前大多數團隊在管理訓練數據時，仍然依賴分散的檔案系統、簡單的資料夾結構或自製脚本，導致以下常見問題：

- 數據版本難以追蹤
- 缺住標準化的元數據管理
- 團隊協作效率低
- 數據準備過程重複且容易出錯
- 難以進行數據血緣追蹤與審計

DatasetForge 旨在解決以上痛點，提供一個專業、結構化、可擴展的訓練數據管理平台。

---

## 2. 項目目標

DatasetForge 的核心目標是成為一個**專業的 AI 訓練數據全生命週期管理平台**，幫助個人及團隊：

- 有效管理大型及多樣化的訓練數據集
- 實現數據的版本控制與可重現性
- 提升數據準備、策展與協作效率
- 為模型訓練提供穩定、可靠的數據來源

---

## 3. 目標用戶

| 用戶類型             | 主要需求                           | 使用場景                     |
|----------------------|------------------------------------|------------------------------|
| **數據科學家 / ML 工程師** | 快速管理、版本控制及匯出數據       | 日常模型開發與實驗           |
| **數據標註團隊**     | 協作標註、數據品質管理             | 大規模數據標註項目           |
| **ML 平台團隊**       | 整合數據 pipeline 與訓練系統       | 企業內部 MLOps 平台          |
| **研究人員**         | 管理實驗數據與可重現性             | 學術研究與論文實驗           |

---

## 4. 項目範圍

### 4.1 核心範圍（In Scope）

- Dataset 的建立、編輯、刪除與元數據管理
- Dataset 的版本控制與歷史追蹤
- 支援常見數據格式（JSONL、Parquet、圖像資料夾等）
- 與物件儲存（MinIO / S3）整合
- 基本數據統計與預覽功能
- 用戶認證與基本權限管理
- Web 介面操作

### 4.2 非核心範圍（Out of Scope）- 第一階段

- 複雜的數據標註工具（Label Studio 整合為可選）
- 自動數據清洗與特徵工程
- 大規模分布式處理
- 多租戶企業級功能
-  advanced 數據血緣與治理

---

## 5. 核心挑戰與解決方案

| 挑戰                     | 解決方案                              |
|--------------------------|---------------------------------------|
| 大型數據檔案管理         | 使用 MinIO/S3 + Presigned URL         |
| 數據版本控制             | 資料庫記錄版本 + 不可變儲存           |
| 多樣化數據格式支援       | 抽象儲存層 + 格式驗證                 |
| 團隊協作與權限           | 基於角色的訪問控制（RBAC）            |
| 數據可重現性             | 版本 + Metadata + 血緣追蹤            |

---

## 6. 預期效益

- 顯著提升數據準備效率
- 降低因數據版本錯誤導致的模型問題
- 改善團隊之間的數據協作體驗
- 為後續 MLOps 與模型訓練 pipeline 打好基礎
